## 👀 Do que se trata?

Vamos mergulhar no uso de folhas de estilo. Prontos para aprender e estimular a imaginação?

**#DibujarteCSS** é uma galeria comunitária de arte feita só com HTML e CSS. Qualquer pessoa pode participar — a ideia não é competir, e sim **compartilhar o processo**, experimentar e se surpreender com o que dá para criar sem imagens nem SVG.

Seja seu primeiro desenho com CSS ou se você já tem experiência, aqui tem lugar para você 💜

## 🤔 Como posso participar?

Você não precisa ser especialista em CSS. A ideia é aprender, tentar e se divertir.

🟣 **Primeiro**, vamos nos documentar sobre as propriedades que mais vão ajudar:

* `background`
* `clip-path`
* `box-shadow`
* `border`

🟣 **Recursos recomendados** para ir mais fundo:

* [Desenho com CSS Gradient](https://css-tricks.com/drawing-images-with-css-gradients/)
* [Single div drawings](https://hacks.mozilla.org/2014/09/single-div-drawings-with-css/)
* [Guia básico para obter imagens com CSS](https://medium.com/coding-artist/a-beginners-guide-to-pure-css-images-ef9a5d069dd2)

🟣 **Depois**, escolha um objeto do dia a dia que te represente e desenhe com CSS. A técnica é livre: realista, cartoon, pixel art, flat… como preferir.

✨ **Opcional:** adicione interação com um pouco de JS.

## 🎨 Quero que meu desenho esteja na galeria

Com certeza! Você pode nos encontrar de duas formas:

1. Abra um **issue** neste repositório, selecione o template `Solicitud de adición de arte a galería` e preencha as informações.
2. **Publique com a hashtag #DibujarteCSS** e marque [@musartedev](https://x.com/musartedev).

Adoramos ver o que você cria 🎨

## 🛠 Stack e desenvolvimento

A galeria roda com:

* Vite + React 18
* Tailwind CSS v4
* Cloudflare Pages (site estático)

### Desenvolvimento local

```bash
npm install
npm run dev
```

Abra http://localhost:5173

### Deploy no Cloudflare Pages

1. [Cloudflare Dashboard](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. Build command: `npm run build`
3. Output directory: `dist`

Ou via CLI:

```bash
npm run deploy
```
